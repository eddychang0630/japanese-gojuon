# 🌸 日文五十音學習 PWA (Japanese Gojuon Web App)

專為完全零基礎初學者設計的日文五十音學習 Web App / PWA，可直接在手機、平板與電腦上使用，並支援離線運作與加入手機主畫面（如同原生 App）！

🔗 **線上使用網址 (GitHub Pages)**:
`https://eddychang0630.github.io/japanese-gojuon/`

---

## ✨ 主要功能特點

1. 🔤 **平假名 & 片假名完整五十音表**
   - 包含清音、濁音對照與記憶聯想技巧。
   - 點擊任一假名即可查看大字卡、羅馬拼音、對應片/平假名與實用記憶口訣。

2. 🔊 **真人發音朗讀（Web Speech API + 高清雲端語音雙備援）**
   - 每個五十音假名與基礎單字均支援點擊發音。
   - 採用日語在地發音引擎，手機與電腦皆能正常發音。

3. 🃏 **互動式記憶閃卡（Flashcard）**
   - 支援翻卡記憶（點擊翻面看羅馬拼音與口訣）。
   - 可根據「行」（あ行、か行...）或「平假名 / 片假名 / 需加強」篩選練習。
   - 難易度標記（難記、還好、已記住）智慧追蹤複習。

4. ✏️ **多模式測驗衝刺（Quiz）**
   - 平假名 ➔ 羅馬字
   - 羅馬字 ➔ 平假名
   - 片假名 ➔ 羅馬字
   - 平假名 ➔ 片假名
   - 綜合混合題庫，即時連勝記錄與結算評語。

5. 📊 **學習進度與成就系統**
   - 記錄已學會字數與完成百分比環形圖。
   - 連續學習天數（Streak）追蹤。
   - 9 款里程碑成就徽章（初心者、答題王、五十音大師等）。

6. 📖 **完全初學者專屬：30天學習計畫 & 入門 Top 20 單字**
   - 附帶發音按鈕的 20 個最實用日本日常單字（你好、謝謝、水、麵包等）。

## 📱 如何存到手機主畫面（當成 App 使用）

### 🍏 iPhone (iOS Safari)
1. 用 Safari 開啟網址：`https://eddychang0630.github.io/japanese-gojuon/`
2. 點擊瀏覽器下方中央的 **「分享」按鈕**（向上箭頭方形圖示）。
3. 往下滑動找到並點擊 **「加入主畫面」（Add to Home Screen）**。
4. 點擊右上角「新增」，手機桌面就會出現精美的「五十音」App 圖示！

### 🤖 Android (Google Chrome)
1. 用 Chrome 開啟網址：`https://eddychang0630.github.io/japanese-gojuon/`
2. 頁面上方會自動跳出「加入主畫面」提示，點擊「安裝」；或點擊 Chrome 右上角 **三個點 (選單)**。
3. 選擇 **「安裝應用程式」** 或 **「加到主畫面」** 即可。

## 📅 給完全不會日文者的建議與學習計畫

### Q: 「應該會先建議背完50音再學單字嗎？」
**答：強烈建議先掌握 50 音的基本認讀！**
- **原因**：日文是由假名拼音構成的語言（就像注音符號或英文字母）。如果連「あ、い、う、え、お」都不認得，背單字時只能靠羅馬拼音（例如 konnichiwa），這樣到後期看到招牌、菜單、日本網站時依然完全讀不出來，且容易產生不標準的發音依賴。
- **最佳節奏**：
  1. 先把 **平假名（46字）** 認熟（約 1~2 週）。
  2. 開始搭配學習 **最簡單的日常單字**（如：ありがとう、ねこ、みず），邊背單字邊驗收五十音拼音！
  3. 接著學習 **片假名**（外來語用，如：パン、コーヒー）。

### 📅 推薦的 30 天達標節奏：
- **第 1 週（平假名上半部）**：
  - Day 1-2：あ行（あいうえお）+ か行（かきくけこ）共 10 字
  - Day 3-4：さ行（さしすせそ）+ た行（たちつてと）共 10 字
  - Day 5-7：複習前面 20 字，用 App 閃卡與測驗刷到 90% 正確率。
- **第 2 週（平假名下半部）**：
  - Day 8-10：な行、は行、ま行
  - Day 11-13：や行、ら行、わ行、ん
  - Day 14：全平假名總測驗，開始讀 App 內的 20 個基礎單字。
- **第 3 週（片假名上半部）**：
  - 對照平假名學習ア行到タ行，利用「對照模式」事半功倍。
- **第 4 週（片假名下半部與衝刺）**：
  - 完成ナ行到ン，並啟動「混合測驗」挑戰滿分與全成就徽章！
